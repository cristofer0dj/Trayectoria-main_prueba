Planteamiento y modelo matemático

Un vehículo autónomo inspecciona una estructura industrial siguiendo una trayectoria 3D y debe cumplir límites de tiempo, rapidez, aceleración, temperatura y curvatura.
r(t) = ((a+bt)·cos t, (a+bt)·sen t, c·t), 0 ≤ t ≤ 4π
T(x,y,z) = 20 + 4x − 3y + 2z + x² + y² + 2z² − xy
Cinemática y geometría
v = r′, a = r″, rapidez = |r′|
κ = |r′×r″| / |r′|³ · τ = (r′×r″)·r‴ / |r′×r″|²
T̂ = r′/|r′|, B̂ = r′×r″/|r′×r″|, N̂ = B̂×T̂
s(t) = ∫₀ᵗ |r′(u)| du
Entorno y análisis local
∇T = (4+2x−y, −3+2y−x, 2+4z)
dT/dt = ∇T·r′ · D_T̂ T = ∇T·T̂
L(p) = T(p₀) + ∇T(p₀)·(p−p₀)
T(p₀+h) − L = ½ hᵀHh, H = [[2,−1,0],[−1,2,0],[0,0,4]]
Condiciones iniciales: tiempo ≤ 4π · rapidez ≤ 3.00 · aceleración ≤ 2.50 · T ≤ 50 · κ ≤ 0.50 (modificables en el panel lateral). Como T es cuadrática, el error de la aproximación lineal es exactamente ½ hᵀHh.
